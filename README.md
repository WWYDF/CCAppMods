# CC App Extension Mods
This is a collection of mods to be injected via UE4SS on the ClarionCorp Ai.Mi Companion App. Mod updates are zipped up into [releases](https://github.com/WWYDF/CCAppMods/releases) and the app will fetch from it occasionally.

You can find the App repository [here](https://github.com/ClarionCorp/app).
